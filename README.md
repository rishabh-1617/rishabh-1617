## 🚀 Featured Projects

<details>
<summary><b>🎯 Predicting Sonar Rocks Against Mines</b></summary>
<br/>

A machine learning classifier that distinguishes between sonar signals reflected off **rocks** vs **mines**, built to explore signal-based binary classification on high-dimensional sonar data.

| Aspect | Detail |
|---|---|
| **Stack** | Python, Pandas, Scikit-learn |
| **Scale** | 60 distinct sonar signal features |
| **Performance** | 98.76% accuracy (Random Forest, best-performing model) |
| **Security** | N/A — local research/academic model |
| **Impact** | Demonstrated ensemble models outperform baseline classifiers on noisy sonar data |
| **Repository** | [github.com/rishabh-1617](https://github.com/rishabh-1617) |

Built a predictive pipeline that classifies sonar signals as rocks or mines using 60 distinct features per sample. Evaluated multiple classifiers and found the **Random Forest ensemble** delivered the strongest generalization, achieving **98.76% accuracy** in final evaluation — validating ensemble methods as the right fit for this high-dimensional, moderately noisy signal dataset.

</details>
